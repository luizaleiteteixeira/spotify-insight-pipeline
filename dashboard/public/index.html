06 · How it works

Six stages, code in control

Models read messy language; code owns accounting, arithmetic, validation, retries, budgets and checkpoints. Every hand-off is a saved file.
Patterns used: a chain of distinct agents · parallel workers on one shared queue · consensus (enricher + independent verifier + adjudicator, majority vote) · advisor (tested, not adopted) · a capped fallback · exact-text caching · Batch API · checkpoints and resume. Front end → serverless API (read-only DB role) → Neon Postgres.
